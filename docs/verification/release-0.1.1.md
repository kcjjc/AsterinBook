## 用户升级步骤

1. 正常关闭旧版，等待进度保存完成。需要备份时，关闭后复制整个阅读数据目录。
2. 运行 0.1.1 安装包，按提示升级，沿用原程序安装位置。无需先手动卸载。
3. 启动新版，原阅读数据目录、书架、进度、书签和排版设置继续使用，无需重新导入小说。

直接运行 EXE 的用户可在退出旧进程后替换为新版 EXE；本次同一应用标识仍读取原有书库定位记录。

当前使用手动安装包升级，没有在线自动更新。以上安装升级采用静默参数，未手动点击图形安装目录页；原生文件选择对话框、无 WebView2、非 C 盘等环境限制仍见 0.1.0 交付记录。
