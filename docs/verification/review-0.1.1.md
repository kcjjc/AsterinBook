1. Important：分页过程中后续正文读取失败时，busy 会变为 false，但已发布页只是章节前缀。仅使用 !busy 判断章末会跳过未读正文。新增故障回归，修复前错误进入第二章；修复后要求 current.end 等于 chapter.bodyEnd，页脚禁用条件同步修正，回归通过。
2. Minor：两次同步按键只覆盖同一事件轮次，未验证真实保存延迟和失败。新增 800 ms 延迟期间重复按键测试、首次保存失败留在原章并可重试的测试，均通过。
